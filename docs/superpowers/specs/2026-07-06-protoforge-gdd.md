## 0. 一句话定义

**ProtoForge 是一个让玩家用"自然语言 + 原语卡牌"设计生物元件的游戏化众包平台。** 玩家用自然语言说出"我想要 XX",LLM 翻译成 Proto 卡牌,玩家拖动卡牌微调,点"开炉"后 Proto 引擎跑出真实评分。玩家的每个方案都是一份**可被科研复用的 Proto 程序**。

---

## 1. 玩家体验循环(游戏内核)

### 1.1 单次开炉的 7 步循环(核心循环)

```
[1] 任务简报(剧情推送)
        ↓
[2] 自然语言输入("我想要...")
        ↓
[3] LLM 翻译 → 原语卡牌自动生成
        ↓
[4] 玩家拖动卡牌:增/删/换位/微调参数
        ↓
[5] 点"开炉" → 锻炉仪式(对应档位时长)
        ↓
[6] 雷达图 + 序列预览 + 风险门提示
        ↓
[7] 玩家决策:
   ├─ 满意 → 存作品
   ├─ 不满意 → 回到 [2] 改 NL 或回到 [4] 调卡牌
   └─ 触发风险门 → 答教学题,可能强制重设计
```

**这个循环 5-30 分钟一次,每次都包含"创意 → 表达 → 调整 → 验证 → 反思"五要素**,符合心流模型。

### 1.2 跨关卡的纵向循环(长循环)

```
新手教程(关卡 1-2) → 玩家学会 4 类卡牌的基本操作
        ↓
委托关卡(关卡 3-7) → 玩家接 5 个真实科研问题,每个出 1 个作品
        ↓
进阶关卡(关卡 8-12) → 玩家学深调参,卡牌变多
        ↓
棘手关卡(关卡 13-15) → 多生物联动 + 冲突约束
        ↓
自由模式(关卡 16+) → 玩家自定义研究问题,导出 Proto 程序到 Stanford
```

## 2. 核心交互详解(主交互 = 方案 ① + ④ + ②)

### 2.1 玩家做的"4 类核心动作"

| 动作 | 描述 | 类比 |
|---|---|---|
| **A. 表达创意** | 自然语言输入"我想要..." | 像给同事发消息 |
| **B. 拼卡牌** | 拖动 4 类原语卡(序列/约束/生成器/优化器)调整结构 | 像玩 Lego/卡牌构筑 |
| **C. 调参数** | 在卡牌上滑动滑块微调权重/阈值/步数 | 像调音台 |
| **D. 看反馈** | 看雷达图、序列预览、风险门 | 像看实验结果 |

**关键**:这 4 个动作是**层层递进**的,新手先只用 A(纯 NL),熟练后用 B(拼卡牌),再后用 C(调参),最后用 D(看反馈做决策)。

### 2.2 卡牌体系(原语级颗粒,LLM 翻译的输出)

**LLM 翻译输出的标准结构** —— 4 类原语卡牌:

```
┌──────────────────────────────────────────────┐
│  [序列卡牌]                                    │
│  类型: DNA / RNA / Protein                    │
│  初始序列: ACTG... (50-500 nt/aa)             │
│  来源: MCMC 上一步提议 / 玩家直接编辑          │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│  [约束卡牌]  × 1-5 张                          │
│  ┌─────────────┐  ┌─────────────┐             │
│  │ target_splice│  │orthogonality│  ...        │
│  │ 权重: 0.8   │  │ 权重: 0.6   │             │
│  │ 目标: SH-SY5Y│  │ 阈值: 0.3   │             │
│  └─────────────┘  └─────────────┘             │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│  [生成器卡牌]                                   │
│  类型: uniform_mutation / biased / ESM3      │
│  提案温度: 0.7                                │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│  [优化器卡牌]                                   │
│  类型: mcmc / gradient_descent                │
│  MCMC 步数: 200                               │
│  接受率阈值: 0.05                             │
└──────────────────────────────────────────────┘
```

**LLM 翻译的 Prompt 规则**:
- 输出必须是**这 4 类卡牌的 JSON 数组**,不能输出自由文本;
- 每张卡牌有必填字段(类型/初始值/参数)和可选字段(权重/约束);
- 玩家 NL 中提到的"目标"(如"在极地菌里表达")必须翻译成至少 1 张约束卡牌;
- LLM 不输出玩家没提到的"高级卡牌"(如"双链稳定性"),只输出 NL 直译的结果 —— 玩家可手动加。

### 2.3 拖动卡牌的 4 类操作(玩家最高频动作)

| 操作 | 触发 | 后果 |
|---|---|---|
| **拖动卡牌位置** | 卡牌在卡牌堆里换位置 | 改变 Proto 程序执行顺序(比如约束先 vs 优化器先) |
| **拖到删除区** | 拖出卡牌堆 | 移除这张卡牌(对应 Proto 里删除这个原语) |
| **点卡牌上的 "+约束"** | 卡牌展开 | 在这张序列/生成器下加新约束 |
| **拖到复制区** | 拖到"复制"图标 | 复制这张卡牌(批量调参场景,如"对每条染色体都加同一约束") |

**类比游戏**:这 4 类操作让 ProtoForge 玩起来像 **Baba Is You**(规则组合)+ **杀戮尖塔**(卡牌构筑) + **欧陆风云**(策略堆叠)。

### 2.4 调参体系(从浅到深的渐进)

**Phase 1 关卡 1-2(新手教程)** —— 玩家只看到 **5 个主滑块**:
- 目标剪接强度
- 脱靶抑制强度
- 约束权重 α
- 约束权重 β
- MCMC 步数

LLM 自动选生成器,玩家不接触。

**Phase 1 关卡 3-7(委托关)** —— 玩家看到 **8 个滑块 + 1 个生成器下拉**:
- 上述 5 个
- 序列 GC 含量
- motif 密度
- 进化距离
- 生成器类型下拉(uniform / biased / ESM3)

**Phase 2 关卡 8-12(进阶)** —— 玩家看到 **12 个滑块 + 3 个生成器 + 2 个优化器**:
- 加"约束叠加方式"(乘 / 加 / max)
- 加"接受率阈值"
- 加"并行温度"(MCMC 的退火参数)
- 等等

**Phase 2 关卡 13-15(棘手)** —— 玩家要**手动平衡多目标冲突**(调"权重 α/β/γ/δ" 4 个权重,目标 4 个细胞系),还要做"序列剪接产物比例预测"的多目标 Pareto 前沿选择。

### 2.5 反馈循环(玩家决策的"信息源")

| 信息源 | 形式 | 决策作用 |
|---|---|---|
| **雷达图**(5 维) | 5 维雷达:剪接强度/正交性/新颖性/多样性/GC 含量 | 知道当前方案"在哪些维度强/弱" |
| **序列预览** | DNA 序列彩色块 + 标注 motif/启子区 | 看出"序列长什么样" |
| **历史曲线** | 折线图:MCMC 迭代的能量下降 | 看出"优化在收敛吗" |
| **风险门提示** | 弹窗:关键词 + 教学题 | 知道"是否触红线 / 哪个设计思路有伦理问题" |
| **锻炉仪式动画** | 火花/进度条 | 营造"等待"感,缓解焦虑 |
| **"类似作品"推荐** | 列表:本关其他玩家的高分方案(脱敏) | 学习"别人怎么设计" |

## 3. 关卡设计(5 类渐进)

### 3.1 关卡总览

| 关卡编号 | 关卡类型 | 任务数 | 难度 | 玩家学到 |
|---|---|---|---|---|
| 1-2 | 纯教程关 | 0(教学) | ★ | 什么是 Proto,什么是卡牌 |
| 3 | 委托关 #1 | 1 | ★★ | 用 LLM + 卡牌做一个生物 |
| 4-5 | 委托关 #2-3 | 1 | ★★ | 学会调主参数 |
| 6-7 | 委托关 #4-5 | 1 | ★★★ | 学会加新约束 |
| 8 | 多生物联网关 | 1 | ★★★ | 学会设计 2 个生物联动 |
| 9-12 | 进阶关 | 4 | ★★★★ | 学会调深参数,理解 Proto 完整语义 |
| 13-15 | 棘手关 | 3 | ★★★★★ | 学会在多目标冲突下取舍 |
| 16+ | 自由模式 | 无限 | ★★★★★+ | 玩家自定义研究问题,导出 Proto 程序 |

### 3.2 三大场景(任务)

| 场景 | 任务 | 玩家学到的 Proto 概念 |
|---|---|---|
| **极地科考队** | 设计耐低温发光菌(基于 Proto 论文 R2) | 序列设计 + 约束 + MCMC 优化 |
| **火星基地** | 设计自修复建材(Phase 2 引入) | 蛋白设计 + ESM3 蛋白语言模型 |
| **NSCLC 医院** | 设计选择性杀伤肺癌细胞的效应元件(Phase 2 引入) | 抗体设计 + 启动子 + 多目标优化 |

### 3.3 5 类关卡的设计规范

#### A. 纯教程关(关卡 1-2)

- **不做研究**,纯教游戏操作;
- 关卡 1 = "什么是 Proto 卡牌":界面介绍、拖动 4 类卡牌的演示;
- 关卡 2 = "如何用 NL 生成卡牌":输入一句"我要发光",LLM 出 4 张卡牌,玩家看到序列预览;
- **通过条件**:看完演示,不需要评分;
- **关键**:教程中**直接显示 Proto 程序的 JSON 输出**,让玩家看到"程序长什么样",消除"这玩意儿是黑盒"的疑虑。

#### B. 委托关(关卡 3-7)

- **5 个独立任务**,每个 1 关;
- 每个关卡有**剧情简报**(2-3 句)+ **目标评分** + **风险门**;
- 玩家自由玩,可以无限次开炉,直到满意存作品;
- **通过条件**:作品评分 ≥ 阈值 + 风险门通过;
- **奖励**:作品解锁下一个关卡 + 1 个"科研贡献徽章"。

#### C. 多生物联网关(关卡 8)

- 玩家要**同时设计 2 个互相作用的生物**;
- 比如:一个生物"分解塑料",另一个生物"吃分解产物"——必须**配对**;
- 玩家用卡牌堆的"复制 + 修改"操作做变体;
- **通过条件**:两个生物都达标 + 相互作用评分 ≥ 阈值。

#### D. 棘手关(关卡 13-15)

- 玩家面对**多目标 Pareto 冲突**:优化 A 必然损失 B;
- 玩家必须**调整 4 个目标权重**,画自己的 Pareto 前沿;
- 任务简报会"明示冲突":"火星基地要耐高温,但耐高温的菌活性必然下降,你选什么?"
- **通过条件**:玩家提交的方案在 Pareto 前沿上(任一权衡点)。

#### E. 自由模式(关卡 16+)

- 玩家**自定义研究问题**;
- 玩家用 NL 描述"我想设计...",LLM 出卡牌,玩家调;
- 玩家方案可**导出为 Proto 程序 JSON**,作为"科研贡献"上传;
- **科研价值**:这些方案会进入 Stanford Proto 社区的"玩家贡献"列表。

## 4. 风险门(游戏化伦理教育)

风险门不是"惩罚",是**"教学机会"**。

### 4.1 L1 关键词扫描(自动)

- 玩家 Proto 程序不包含"裂解酶 / 毒素 / 耐药基因 / 增强子(人体内)/ 病毒元件"等 30+ 关键词;
- 触发即提示"你设计了一个有风险的元件,需要答 2 道教学题才能继续"。

### 4.2 L2 教学题(多选)

每个红线配 2-3 道题,题目分两层:

| 层 | 形式 | 例子 |
|---|---|---|
| **情境判断** | "以下哪个场景应被禁止?" | "裂解酶基因整合到人体共生菌中" ❌ |
| **原理理解** | "为什么这个设计有风险?" | "因为裂解酶会破坏细胞膜,失控会导致宿主死亡" |

通过条件:L2 ≥ 2/3 正确。

### 4.3 L3 长期记录(Phase 3)

- 玩家每次答错会被记入"伦理学习档案";
- 累计 10 次未通过的玩家,在作品墙上显示一个"伦理学习者"徽章 —— **不是污名,是荣誉**(说明玩家在做深度思考)。

## 5. 调参体系(从浅到深的体系化设计)

**核心原则**:Proto 有 7 大原语(Sequence / Segment / Construct / Constraint / Generator / Optimizer / Program),每个原语都有参数。**玩家调参不是"猜数字",而是"理解每个原语在 Proto 程序中的角色"**。

### 5.1 Proto 原语 ↔ 游戏卡牌 ↔ 玩家心智模型

| Proto 原语 | 游戏卡牌 | 玩家心智 | 比喻 |
|---|---|---|---|
| **Sequence** | 序列卡 | "DNA 文本" | 像文字编辑器 |
| **Constraint** | 约束卡 | "评分标准" | 像裁判打分 |
| **Generator** | 生成器卡 | "变异方式" | 像骰子 / 进化压力 |
| **Optimizer** | 优化器卡 | "搜索策略" | 像登山路径选择 |
| **Segment** | 段落卡(Phase 2) | "设计子区域" | 像文档分章节 |
| **Construct** | 装配卡(Phase 2) | "整体拼装" | 像积木成品 |
| **Program** | 程序卡(Phase 2) | "完整流程" | 像流水线 |

**新手教程** 只教前 4 个(序列/约束/生成器/优化器),**进阶关**才教后 3 个(段落/装配/程序)。

### 5.2 5 类参数调参"教学关"

每类参数有一个"教学关",玩家通过这个关卡真正理解这个参数**为什么影响评分**:

| 教学关 | 参数 | 玩家实验 |
|---|---|---|
| 教学 1: 启子强度 | 序列 GC 含量 | 调高 GC → 看到启子活性变化 |
| 教学 2: 约束权重 | α / β / γ | 调权重 → 看到评分雷达变化 |
| 教学 3: 生成器温度 | MCMC 提案温度 | 调温度 → 看收敛曲线变化 |
| 教学 4: 优化器步数 | MCMC 步数 | 调步数 → 看是否到达最优 |
| 教学 5: 多目标冲突 | Pareto 权重 | 调冲突 → 看前沿变化 |

## 6. 剧情与世界观(基于 3 大场景的"最小化叙事")

**关键决策**(用户 2026-07-06 反馈):"剧情调性取决于研究目标" —— 不预设大世界观,而是**为每个研究任务写一段"科学简报"**,让剧情服务于科研。

### 6.1 极地科考队(关卡 1-7)

- **简报**:"2099 年,南极科考站坍塌,救援队要在 -80°C 黑夜里找到幸存者。他们委托你:设计一段**只能在极地菌株里正确表达、不能在人细胞系里误表达**的'诱导型发光启动子 + 内含子'组合。"
- **研究意义**:复刻 Proto 论文 R2(32% 成功率的内含子设计);
- **叙事价值**:"极地科考队"给玩家紧迫感(救援在即),"诱导型发光"给玩家具体目标,"人细胞里不表达"是科学边界(防止误用)。

### 6.2 火星基地(Phase 2 引入,关卡 8-12)

- **简报**:"22 世纪,火星基地的外墙被火星尘暴侵蚀。你要设计一种**能自我修复**的工程菌 —— 它能在火星环境下(-60°C、低压、高 CO₂)存活,分泌'生物水泥'修复裂缝。"
- **研究意义**:蛋白设计(耐极端环境蛋白 + 自修复分子分泌);
- **叙事价值**:"火星基地"具科幻感,让玩家觉得"我的设计有未来价值"。

### 6.3 NSCLC 医院(Phase 2 引入,关卡 13-15)

- **简报**:"2087 年,非小细胞肺癌(NSCLC)依然高发。你要设计一种**选择性治疗元件** —— 只在 NSCLC 细胞里激活,在健康肺细胞里沉默。"
- **研究意义**:复刻 Proto 论文里"NSCLC 选择性治疗效应元件" 5 阶段门控(EGFR 微蛋白 + 增强子 + 启动子 + 内含子 + 3'UTR);
- **叙事价值**:"救人"给玩家使命感,5 阶段门控是真实的复杂研究问题。

### 6.4 剧情的总基调

- **不预设"我是帝国 / 反抗军 / 英雄"** —— 玩家是"生物工程师 XX 号",接项目单;
- **每个任务简报都强调"科研价值"** —— "你的设计可能被实际湿实验验证,真正帮到极地科考队 / 火星基地 / 医院";
- **结尾给"贡献感"** —— 玩家作品导出时显示"你的 X 号作品已进入 Stanford Proto 社区候选列表"。

## 7. 玩家动机与激励系统

### 7.1 内驱 vs 外驱

| 动机类型 | ProtoForge 怎么设计 |
|---|---|
| **能力成长(autonomy)** | 关卡逐步解锁,从浅调到深调,玩家感受到"我变强了" |
| **创意表达(creativity)** | 同一关卡玩家可以走 N 条不同路径,无标准答案 |
| **社会贡献(purpose)** | 玩家作品可上传到 Stanford 社区,真正用于科研 |
| **收藏收集(collection)** | 5 大徽章系统(急锻者/标准锻匠/古法锻师/晶种培育师/伦理学习者) |
| **竞争(comparison)** | 关卡排行榜(脱敏,只显示玩家昵称 + 评分 + 几句设计说明) |

### 7.2 徽章系统(8 大徽章)

| 徽章 | 触发条件 | 荣誉感 |
|---|---|---|
| 急锻者 | 10 次 4090 档开炉 | 硬件强 |
| 标准锻匠 | 10 次 3060 档开炉 | 主流玩家 |
| 古法锻师 | 10 次 CPU 档开炉 | 我慢但我坚持 |
| 晶种培育师 | 10 次长任务完成 | 我能等 |
| 风险评估师 | 答对 20 道风险门教学题 | 懂伦理 |
| 蛋白预言家 | 设计的蛋白 pLDDT > 0.9 | 准 |
| 序列诗人 | 设计的序列 GC 在 0.4-0.6 | 美 |
| Stanford 学者 | 作品进入社区候选列表 | 真科研贡献 |

### 7.3 防弃坑设计

## 9. GDD 验收标准(Phase 1)

✅ GDD 通过必须满足:

1. 玩家从开游戏到通关 1 个委托关,**完整跑通 1.1 节 7 步循环**;
2. 玩家能用 NL 输入"我想要...",**LLM 3 秒内输出 4 类原语卡牌**;
3. 玩家能拖动 4 类卡牌的 4 种操作(位置/删除/复制/加约束);
4. 玩家能从 5 个主滑块起步,**逐步解锁 12 个滑块**;
5. 风险门 L1 + L2 触发正确,**L3 长期记录开始累计**;
6. 5 类关卡(教程/委托/联网/棘手/自由)Phase 1 至少出**前 2 类**;
7. 8 大徽章系统**至少 3 个**能解锁;
8. 玩家作品能**导出为 Proto 程序 JSON**,可被 Stanford 社区复用。
