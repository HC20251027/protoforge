## 0. 一句话定义

**ProtoForge(原体锻炉)是一个策略游戏化的合成生物学众包平台。** 玩家用"自然语言 + 4 类原语卡牌"代替写 Proto 代码,在 3 大科幻任务场景中设计出能解决真实问题的生物元件;后端跑真 Proto 引擎 + ML 模型,玩家方案可导出到 Steam 创意工坊,作为论文 R2 任务的玩家候选集。

## 1. 目标用户

| 维度 | 目标用户 |
|---|---|
| **身份** | 装 Steam 的中国大学生(本科/研究生/博士) |
| **硬件** | RTX 3060+ 独显(Steam 装机主流) |
| **动机** | 对 AI/生物/编程感兴趣,觉得"游戏化科研"好玩 |

- 真正做科研的人(他们直接用 Proto)
- 不装 Steam 的玩家(不装 Steam = 不在目标用户范围内)

## 4. 游戏类型定位

**ProtoForge = 策略游戏**(杀戮尖塔 + 欧陆风云 + Baba Is You 辅助)

- **核心类比**:**杀戮尖塔**(卡牌构筑) + **欧陆风云**(策略堆叠)
- **辅助类比**:Baba Is You(规则组合的玩法深度)
- **不是放置类** — 玩家要"及时管理"(同时锻造多个 + 等待时长决策 + 退出风险评估)
- **放置只是部分环节**(长任务挂着),不是主体

---

## 5. 4 档难度定位(不跟硬件挂钩)

| 档位 | 时长 | 难度 | 玩法类型 | 徽章 | 心流类比 |
|---|---|---|---|---|---|
| **急锻** | 2-5 秒 | ★ 易 | 卡牌构筑(实时决策) | 急锻者 | 杀戮尖塔单回合(压缩 1/6) |
| **主锻** | 30 秒 - 2 分钟 | ★★ 中 | 卡牌 + 策略堆叠(短策略) | 主锻匠 | 欧陆风云单回合(压缩) |
| **古法锻** | 5-15 分钟 | ★★★ 难 | 放置类(挂机 + 离线惩罚) | 古法锻师 | 文明 6 短回合 + 退出风险 |
| **晶种培育** | 30 分钟 - 2 小时 | ★★★★ 极难 | 纯放置(24h 挂机,退出风险) | 晶种培育师 | 暗黑破坏神挂机 + 多队列 |

**关键设计**:
- 4 档**不跟硬件挂钩** — 玩家**主动选难度**
- 启动时**默认走急锻(2-5 秒)**,所有玩家都能流畅玩
- 玩家可在 Settings 升级档位
- **可同时锻造多个**:急锻/主锻 1 个,古法锻 3 个,晶种培育 5 个 — 队列管理是策略

## 6. 退出惩罚(4 档都生效)

**逻辑**:ProtoForge 后端跑的是**真实计算**(不是游戏内置倒计时),计算在本地 Python 进程里真实发生。

- 玩家退出时**计算已跑完** → **结果保留**,玩家回来直接看到
- 玩家退出时**计算还没跑完** → **结果丢失**(失败),玩家回来看不到
- UI 顶部红色横幅:**「⚠️ 锻造中退出游戏会有概率失败」**
- 玩家**看不到具体百分比** — 概率失败的真正决定因素是计算进度,UI 只显示提示

## 7. 首次启动引导页(3 步配置,只出现 1 次)

```
第 1 步:选择 LLM 模式
   ☐ ☁️ 云 API(推荐)— 便宜/效果好,DeepSeek ¥0.001/次,Claude/GPT 可选
       ↳ [免费 API 渠道推荐 → GitHub 跳转]
   ☐ 💻 本地 LLM(已内置 Qwen2.5-7B,无需联网,但 4GB 显存以下会卡)
   ☐ 🎮 纯滑块(不接 AI,完全手动,可玩但慢)

第 2 步:按选择弹对应表单
   云 API → 填 base_url / model / api_key
   本地 → "正在加载 7B 模型,5-10 秒..." 进度条
   纯滑块 → 跳过

第 3 步:硬件检测 + 档位匹配
   "你的显卡:RTX 3060 8GB → 默认档位:急锻(2-5 秒)"
   (急锻/主锻/古法锻/晶种培育 4 选 1,默认急锻,可在 Settings 改)
   [开始游戏]
```

**关键洞察**:完整封装 ≠ 零配置。玩家**必须引导一次**,但**只做这一次**。

|---|---|
| **导出方式** | **通关后自动上传 Steam 创意工坊**,玩家不点按钮 |

| **Stanford 合作** | 客户端零感知 — 服务端怎么对接 Stanford 是 ProtoForge 团队后端的事 |

## 9. 3 大任务场景(剧情,gdd.md §6 维持原状)

| 场景 | 剧情叙事 | 玩家扮演 |
|---|---|---|
| **极地科考** | 2099 年,南极科考站坍塌,救援队需要"耐-80°C 发光菌",**林溯要设计"只能极地菌表达、人细胞沉默"的内含子** | 救人的工程师 |

- 玩家是"生物工程师 XX 号",接项目单
